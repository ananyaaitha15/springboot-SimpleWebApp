# spring boot simple web application

A simple backend application built using Spring Boot demonstrating REST APIs, CRUD operations, and database integration using Spring Data JPA.

## Features

- REST API endpoints
- CRUD operations
- Layered architecture
- Spring Data JPA integration
- H2 in-memory database

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- H2 Database
- Maven
